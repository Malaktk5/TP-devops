Exercice 1.2 : Branches et fusion avec conflit
bash
git switch -c feature/login
echo 'print("Page de connexion")' > app.py
git add app.py
git commit -m "Ajout de la page de connexion"
git switch main
echo 'print("Bienvenue sur la page principale")' > app.py
git add app.py
git commit -m "Modification du message de bienvenue"
git merge feature/login
cat app.py
nano app.py
echo "# Conflit resolu" > CONFLITS.md
echo "Fichier : app.py" >> CONFLITS.md
echo "Cause : la meme ligne a ete modifiee sur main et sur feature/login." >> CONFLITS.md
echo 'Resolution : j ai supprime les marqueurs <<<<<<<, ======= et >>>>>>> du fichier.' >> CONFLITS.md
git status
nano app.py
git add app.py CONFLITS.md
git commit -m "Resolution du conflit entre main et feature/login"

Dans nano app.py, tu as supprime les marqueurs. Le fichier final contient :

print("Bienvenue sur la page principale")
print("Page de connexion")
Exercice 1.2 : Question de reflexion (rebase)
bash
git switch -c test-main feature/login~1
echo 'print("Bienvenue sur la page principale")' > app.py
git add app.py
git commit -m "Test rebase : modification sur main"
git switch -c test-feature feature/login
git log --oneline --graph --all
git rebase test-main
nano app.py
git add app.py
git rebase --continue
git log --oneline --graph --all
git switch main
git branch -D test-main test-feature
git log --oneline --graph --all
Exercice 1.3 : Depot distant

Sur le site GitHub : creation du depot public vide TP-devops (compte Malaktk5).

bash
git switch main
git branch
git remote add origin https://github.com/Malaktk5/TP-devops.git

git push -u origin main
git remote -v
git log --oneline --graph --all
cd ~

git log --oneline --graph --all
